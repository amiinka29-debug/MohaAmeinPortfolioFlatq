# MOHA AMEIN Portfolio

Professional personal portfolio website.

## Files
- `index.html` — website structure
- `style.css` — complete responsive styling
- `script.js` — navigation, dark mode, animations, filters and contact form

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## GitHub Pages
Upload all three files to the root of a public GitHub repository, then enable:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.
